# Проект обмена
## О программе
Проекты, поддерживающие непрерывный обмен между программами Aveva - Tekla - Revit

## Polymetal.Tekla.Client, Polymetal.Tekla.Client.v2018, Polymetal.Tekla.Client.v2021
Расширение Tekla Structures, которое запускается при запуске Tekla Structures. При сохранении работы в Tekla Structures
запускается процесс обмена.

Также на данное расшерение возложены обязанности по доставке файлов (dll) разрабатываемых утилит ПМИ с диска K
на компьютеры пользователей

## Polymetal.Revit.Client
Надстройка Revit, которая запускается при запуске Revit. При сохранении работы в Revit
запускается процесс обмена.

Также на данное расшерение возложены обязанности по доставке файлов (dll) разрабатываемых утилит ПМИ с диска K
на компьютеры пользователей

## Polymetal.E3D.Ifc
Утилита E3D, формирующая данные для экспорта, запускающая Polymetal.E3D.IfcServer.exe и через pipe передающая данные приложению для выгрузки ifc.
Отдельное приложение запускается, тк Aveva 32 битное приложение, для выгрузки используется 64битное приложение.

## Polymetal.E3D.IfcServer
Приложение, общающееся через pipe с Aveva E3D, и создающее ifc файл (используя Xbim) из полученных данных
